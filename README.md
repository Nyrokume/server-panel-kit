# Пульт — тестовая панель удалённого управления серверами и ПК

Тестовый многостраничный React-дашборд (UI-кит) корпоративной панели удалённого управления парком серверов и рабочих станций. Для организаций-арендаторов.

> **Только демо-данные.** Панель ничего не подключает к реальным машинам: нет удалённого выполнения команд и нет захвата экрана. Все показатели, терминал и «экраны» генерируются локально из сидов.

## Стек
- React 19 + Vite + TypeScript
- shadcn/ui (реальные компоненты через CLI, стандартная тема `radix-vega`), Tailwind v4
- Recharts v3 через shadcn Chart; числа и дельты — ru-RU (порт сниппета `44-chart-format`)
- React Router 7, тёмная тема по умолчанию + переключатель, командная палитра (⌘K)
- GrowthBook — слой фич-флагов для A/B (локально, без сети)

## Страницы
Обзор парка · Состояние системы · Машины (список) · Карточка машины · Оповещения · PowerShell (веб-терминал, демо) · Просмотр экрана (демо) · Процессы · Диски (S.M.A.R.T., ввод-вывод) · Пользователи и роли · A/B-тест · Настройки.

## Запуск
```bash
npm install
npm run dev      # разработка
npm run build    # сборка (tsc + vite)
npm run preview  # предпросмотр сборки
```

## A/B
Эксперимент `overview_layout` (контроль ↔ сплит-доска) + `overview_cta` (текст кнопки). Назначение детерминированное и «липкое» по браузеру, события пишутся в локальный лог, результаты — на странице «A/B-тест». Предрегистрация: `src/lib/ab-protocol.md`.
