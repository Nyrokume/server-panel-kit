# A/B preregistration — обзорная страница панели (демо)

- **ID/версия:** overview_layout_cta / v1 (тестовая панель).
- **Решение:** какую раскладку обзорной страницы и формулировку главной кнопки сделать стандартной.
- **Гипотеза/механизм:** для ИТ-администраторов корпораций раскладка «сплит-доска» (KPI и тренд слева, роли и списки справа) быстрее приводит к переходу к списку машин, чем линейная «строка KPI → графики», потому что ключевые действия ближе к сводке.
- **Активы:** вариант раскладки — `src/pages/Overview.tsx` (`layout`); текст кнопки — `overview_cta`.
- **Популяция/триггер:** посетитель панели; экспонирование — первый показ обзорной страницы.
- **Единица рандомизации/анализа:** посетитель (липкий `id` в браузере), хеш GrowthBook, 50/50, один слой.
- **OEC (primary):** конверсия в клик по главной кнопке обзора = клики / показы, направление — рост, окно — сессия.
- **Guardrails:** ошибки консоли = 0; время до интерактивности обзора; доля отказов от списка машин.
- **Метод:** двусторонний, α = 0,05, мощность 80 %; фиксированный горизонт; множественность — Holm по двум флагам.
- **Движок:** GrowthBook SDK (`@growthbook/growthbook-react`), локальные определения флагов, трекинг в локальный лог.
- **Go/No-go:** внедрять вариант при значимом приросте OEC без ухудшения guardrail; иначе — оставить контроль.
- **QA:** страница «A/B-тест» позволяет принудительно включить любую группу и сбросить лог (A/A-проверка).

Примечание: в демо значения показов/кликов синтетические (иллюстрация чтения результатов); реальные клики этого браузера добавляются к своей группе. Сеть не используется.
